# 📈 Power BI Reports

Business intelligence reports built in **Microsoft Power BI**.

| Report | Description |
|---|---|
| **Canada - Unemployment Rate Analysis (Pre and Post Pandemic Comparison)** | Compares Canadian unemployment rates before and after COVID-19 to show how the pandemic affected the labour market |
| **Cookies Company Financials Analysis** | Financial dashboard covering the company's revenue, costs and profit |

## How to view
Download a `.pbix` file and open it in [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free).
